# 材料：入库、定级、核对

## 1. 目录约定（一个学期一个工作区）

```
<学期>/
├── 0_进度总览.md            给用户看：有哪些成品、先看哪份、做到哪
├── 1_老师讲义/<课程>/       A 级
├── 2_学习包/<课程>/         成品 PDF（只放 PDF）
├── 3_计划与课表/            课表 ics
├── 4_参考资料_往年/<课程>/  B 级
├── 5_教材原书/<课程>/
├── 6_视频课/
└── _系统/                  学习者档案.md、日志.md、源码md/、工作记录/<任务名>/、tmp/build/
```

命名：投喂材料 `MMDD_<精简中文>`（老师的再加原始文件名后缀，如 `0901_上机1题单_Practice1.pdf`）；我们的成品按序号/周次命名不加日期（`泛函_期中_0a_零基础补课.pdf`）。讲解里的原文锚点写老师的原始文件名，不写磁盘全名。批量改名后同步改进度总览和工作记录里的路径，**日志不回改**（历史记录只追加）。

## 2. A/B 级

- A 级 = 老师本学期发的，唯一准绳（讲到哪、用什么编号、什么记号）。
- B 级 = 往年学长材料、公开教材：只能补深度、补题。
- **判级先看年份/版本号**。老师随堂发，按定义不会有完整版；「内容完整」恰恰是往年材料的特征。判年份的可靠办法：拿文中出现的具体日期反查星期几。
- 「老师这次没发」≠「老师不会发」。别从一次观察推出永久结论写进规范。
- 新一册通常是累积版：逐页抽文本 diff，写清「前 N 页没变、哪页改了、新增哪些节」。

## 3. 作业题单

同学打字整理的版本会：漏条件（周期条件没抄）、缩题（任意 p≠q 缩成 ℓ¹ vs ℓ²）、自加错误 Hint、更正只发在群里。
→ 逐题定位老师原文页码，差异写在讲解的题目前面；截图里有黑板照片就裁剪放大核对手写；提醒用户「群里有更正就截图发过来」。

## 4. 原文本身会错

- A 级不等于无错：「A 级优先」管的是范围和编号，不替老师的笔误背书。
- 查法：反演/变换类题把老师答案做正变换（数值积分）与题面比；计算题 sympy 重算；表格逐行验。
- 勘误写进 `_系统/工作记录/讲义勘误.md`，以后写讲解、自查都对着它查。新一版到货要复核旧勘误还在不在。
- 某些章节错误率显著更高（例题一节五题错三题），这种章节后续一律代回验证。

## 5. 难读的源格式

| 源 | 坑 | 做法 |
|---|---|---|
| PPT 转的 PDF（物理课件） | 文字层公式被打散成乱码（`2 2 30 cos[ ] ( x ) y A t`） | `page.get_pixmap(dpi=140)` 渲染成图看；文字层只用来定位页码 |
| `.ppt` 原件 | OLE 抽文本会丢光公式 | 请用户用 WPS/PowerPoint/Keynote 导出 PDF |
| 扫描版教材 | 无文字层 | 渲染看图；要文本用 RapidOCR（macOS Vision 不支持中文；`pip install rapidocr-onnxruntime` 中文效果好） |
| 板书照片 HEIC | 读不了 | macOS 用 `sips -s format jpeg -Z 2200` 批量转；先转录成 md 当这一讲的原文，标 `⟨缺口 N⟩`（老师跳步/写略处），补全缺口是讲解的主体；转录拿不准的地方标出来请用户看照片确认 |
| 讲义 PDF 文字层 | 丢闭包横线、上标 | 凡裁定讲义有错，先渲染那一页 |

## 6. 排期依据

- 课表 ics：多数事件是 `RRULE`，必须展开 `INTERVAL`（=2 是隔周）；课程名注意歧义（grep「物理」会同时命中「数学物理方程」）。
- 只认两类依据：课表里的下次课、用户说的截止日。「这章应该下周才讲」这种猜测别写；课件到的当天多半就是当天讲的。
- 截止日用户自己清楚，不要反复追问。
