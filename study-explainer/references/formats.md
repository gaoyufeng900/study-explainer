# 产出格式

## 目录
1. 作业讲解（五段式）
2. 对照导航卡
3. 考前复习：零基础补课册 + 题型解法卡
4. 编程上机 / 代码作业：带做卡（六步）
5. 物理章节包
6. 旧版讲义骨架（备查）

所有格式都服从 `writing.md` 的现行写法；冲突时以 `writing.md` 为准。

---

## 1. 作业讲解（每题、每小问都走五段）

1. **题目在问什么**：人话复述，考什么、要证/算/构造什么；小问之间什么关系。依赖图的题先嵌原题图。
2. **涉及知识点**：要用的定义/定理，带讲义编号与页码，精确陈述 + 直觉；点出核心工具。
3. **解题思路**：正式解答前先给逻辑骨架，讲**为什么**用这个方法；关键技巧提前点出。
4. **解答**：完整无跳步，每步有依据。计算终答 `\boxed{}`，证明以 $\blacksquare$ 收尾。（语言：现行中文；旧版是英文 + 中文注释。）
5. **结果总结**：一行结论；证明题点出最关键的一步；同类题的方法论。

另：题面以老师原文为准，打字版的差异在题前注明；题图读不清标「需要人工确认题图」并给出能确定的部分。

## 2. 对照导航卡（用户以视频/中文教材为主线时）

只做主线做不到的事，短：
- 老师编号 ↔ 视频集数/时间段 ↔ 教材章节的对照（一张表即可）
- 老师独有、视频和教材不讲的内容：按现行写法讲清
- 老师讲义的笔误：写「原文 X，应为 Y，理由」，每条都对渲染页核过
- 哪些可以跳、考前看哪几集

## 3. 考前复习（两份配套）

**0a 零基础补课册**：前置知识 K1、K2…按依赖排，每条「人话 → 带数例子 → 反例 → 小图 → 后面用到它的 T 编号」。

**0b 题型解法卡**：
- 第 1 页：总表（题型｜认出它的信号｜核心方法｜作业原型题号｜真题/练习题对应）+「这几天怎么用」（先补 K → 读题型 → 闭卷重做原型 → 做同类题）。
- 每个题型固定小块：
  - ⓪ 先补哪几条（指向 0a 的 K 编号）
  - ① 认出它：题面出现什么字眼就是这类
  - ② 解题套路：每步「做什么 + 为什么 + 靠哪条定理」
  - ③ 要用的知识点：「条件 ⇒ 结论」+ 直观 + 条件缺了会怎样；最易漏的条件单独点出
  - ④ 原型题：完整中文解（作业题以已验收的作业讲解为准、内容一致；没有现成讲解的讲义例题要自己做并独立核对）
  - ⑤ 考场写法：英文模板句 + 易错
- 最后一节「判断题怎么答」：真/假 + 一句依据（定理名或反例名）。

阻断项通常写：全部作业题都在某个 ④ 里（核对记录逐题打勾）；0b 的 ⓪ 指向的 K 真实存在、0a 写的 T 编号与 0b 一致（脚本交叉检查）；表格各 ≤ 2 张；无「显然/易知」。

## 4. 编程上机 / 代码作业：带做卡

适用于编程零基础的读者。一张卡讲 1–2 题，**宁可多切卡，不许把一题压成一两页**。每题固定六步：

**① 题目完整翻译**：题单该题原文（注明第几页）、notebook 里该题说明、代码里每条 `# TODO`/注释、Fixed check / Required evidence 原文，逐段全译并标出处。附术语表（英文｜中文｜一句话），同词不同义要提醒（residual 在一题是残差、另一题是剩余部分）。告诉读者 PDF 在哪。

**② 它在问什么**：一两句人话——写出什么、输入输出是什么、和前面哪题、哪块数学相连。

**③ 数学模型（最重要）**
1. 先写**菜谱**：中文写算法通用步骤（「对每一轮 k：对下面每一行 i：①…②…」）。
2. 用题单的小例子**一次只做一个动作**手算（先只消第一列的 6，再消 −4，再做第二列），每个动作写「倍数怎么来 → 整行怎么减 → 结果」。
3. 每个动作后放「✋ 先自己算」小框，紧接着「核对」。
4. 每步画出矩阵/向量当前状态；跟踪信息（倍数、原行号）写在行旁、换行时跟着搬。
5. 手算结果对上 Fixed check，说明「这就是检查格要的东西」。
6. 手算与菜谱逐条对照一张表。

**④ 名字来源表**：这格每个名字｜从哪来（本格造的 / 前面第几格 / 函数内部临时）｜是什么｜在哪看得到；外加「到目前为止每一格造了什么」累计清单。固定比喻：**变量＝贴标签的盒子；函数＝机器，入口名≠外面的名字**（榨汁机的「水果槽」放进去的是「苹果」）。同名多套（函数里的 `L`、外面的 `L_lu`、答案 `L_practice`）画对照表。

**⑤ 转化成代码**
1. 整格按块标注（准备/外层循环/内层循环/要填的/收尾），老师写好的每行逐行讲：代码｜意思｜对应手算哪步。
2. 菜谱 ↔ 代码零件对照表（「第 i 行第 k 列的数 ↔ `U[i, k]`」）。
3. **你先写**：列出要填的空和零件提示。
4. **参考答案**（放在「你先写」之后）+ 逐块翻译图 + 和上一题同构写法对照。
5. 代入数字把整个循环跑一遍，每次迭代写出变量取值和数组状态。
6. 操作步骤（改哪个 `...`、哪个开关改 True、对哪两格 Shift+Enter）+ **真实运行得到的**期望输出。

**⑥ 结论 + 找错**：说明了什么、和前后题的联系；常见错误 1–3 个——错误版本 → **真实跑出来的**错误输出 → 怎么从报错和异常数字倒推（例：`U[k, k+1:]` 写成 `U[i, k+1:]`，L 里冒出 −5.25，用第一次消元的数字一对就定位）；老师写好的代码也做一个「改一个字符」的变体；教读 `AssertionError` 的 `---->` 箭头。期中期末「给一段错误程序找错改正」就靠这节练，每题都要有。

必须单独成段专门讲的点：`=` 两边同名不是方程；`*` 与 `@`；`range(a, b)` 不含 b、倒着数；切片「刀口图」；Python 从 0 数、题单从 1 数，两套编号并排；名字来源。

硬性：输出必须真实运行得到；用与用户**同版本**的环境跑（版本不同，库的调用次数、提示文字会变）；**不要碰用户自己的环境**，另建镜像 venv。逐行表每行解释必须各不相同、点名具体变量，不许脚本批量生成。

## 5. 物理章节包

重心是**会做题**（考试几乎全是填空和计算）：
- 理论讲够用：定义、物理图像、适用条件、和哪些题型挂钩。
- 课件每道例题完整解，解完抽套路（看到什么条件想到什么方法、哪步最易错）；每张卡再补 2–4 道教材同类题，标「补充题，非老师课件」；标出每题通常以填空还是计算出现。
- 卡末「本节题型速查表」：题型｜识别特征｜首选方法｜常见坑。

三条硬要求：
1. **每个方程讲清凭什么能列**：受力分析（几个力、方向、为什么）、坐标原点为何这么选、用哪条定律及为何能用、近似条件（去掉会怎样）、每个负号的含义。标杆：两弹簧夹一物体右移 x，左弹簧拉伸、右弹簧压缩，两个 kx **同向叠加**才是 −2kx。
2. **微分方程真解一遍**：特征方程 → 通解 → 化成 A cos(ωt+φ)（写出 A、φ 换算）→ 代初始条件。老师写「其通解为」的地方全部补。
3. **图截图嵌入**：受力图、旋转矢量图、曲线、电路图。

课件公式必须**渲染成图看**（PPT 转的 PDF 文字层是乱码），见 `sources.md`。

## 6. 旧版讲义骨架（备查，现行写法下不再强制）

封面 → 知识树总览（依赖图）→ 前置补丁 → 正文逐条精讲（定义 8 步 / 定理 10 步）→ 小节总结 → 易错点 → 自测题 → 批注区 → 自测题完整答案（放全文末）。用户读旧成品或明确要求「完整讲义」时参考。
