# 验收

## 1. 什么算不合格

**阻塞（退回或定点修补）**
- 数学错（独立重推关键步骤；排版工整 ≠ 数学对）
- 引用定理时前提不满足（Egorov 要有限测度；一致有界原理要定义域完备；Dirichlet 核不是逼近恒等）
- 漏讲原文条目、漏题（含「证明从略」的引用型定理）
- 公式没渲染、代码块被压扁、图没嵌
- 越界讲了老师还没讲的内容
- 违反**当前**写法要求（该中文的写成英文证明、该短的灌水、禁用词）

**不阻塞**：孤悬标题、行距、页数、字距、表格宽度。顺手改，改不动就记进日志往下走；小修补并进下一轮任务开头，不单开返工轮。（用户：「我们不要求精益求精……能看得过去就进行下一项」。）

## 2. 程序化扫描（每批必跑）

```bash
python3 scripts/check_all.py 成品.pdf [更多.pdf] [--md 源码.md ...]
```

| 检查 | 抓什么 | 为什么需要它 |
|---|---|---|
| `check_raw_tex_prose.py` | 正文里的 `x_k`、`_{`、`\lambda`、`)^T` | 执行方多次丢掉行内公式的反斜杠，`\(x_k\)` 变 `(x_k)` |
| `check_raw_math.py` | 正文字体里字面的 `^` | `(L^p)` 一个反斜杠都没有，上一条抓不到；XeLaTeX 排的上标不会留 `^` |
| `check_orphan_heading.py` | 页底只剩标题、正文在下页 | 引擎认为完全合法，日志零警报 |
| `check_code_blocks.py` | 代码围栏被压成普通段落（`python`/`text` 标记漏出、行数对不上 md） | 借用了不处理代码围栏的构建器，执行方「逐页目检通过」也没发现 |

四类两两正交，谁也替代不了谁。XeLaTeX 日志对它们全是零。

校准陷阱（都踩过）：
- 必须**按字体排除代码**（本流水线代码字体是 Menlo），否则 `x_new`、`A_neg`、讲 Markdown 时引用的 `$x^2$` 会误报成百上千。
- 正则太糙会造假缺陷：搜 `1.8` 找越界，命中的全是「§1.8 会用到」的合法前瞻。
- 孤悬标题按标题颜色判定，换了模板要用 `--color` 传新标题色。

**程序化不等于免检**：每条命中都渲染原页确认。新的「只能靠眼睛」的项，先想能不能用 PyMuPDF 的位置/颜色/字号/字体判定。

## 3. 人工核对清单

1. 覆盖：对照原文条目/作业题号清单逐个找到正文位置。**表格里打的勾要回查正文**——出现过写着「已验证拓扑公理」但正文只有一句结论。
2. 数学：每个证明逐步成立；计算题代特殊点/对称性/已知特例；反例正反两个方向都验；讲义勘误对勘误表查，不对原文查。
3. 执行方写的「⚠️ 讲义存疑」：每条渲染原页看。出现过文字层丢了闭包横线，执行方据此说老师证明有漏洞——其实没错。
4. 计数类结论先确认口径（各卡标题格式不同，grep 会误判「缺题」）。
5. 篇幅判断只能逐条读：页数少字数不一定少，字数少内容不一定少。不要用「字节/原文页」衡量 PPT 类材料（逐步动画有大量重复页）。
6. **返工件全量重扫**：修复动作本身会引入新缺陷（修孤悬标题时新写的导语里又出现了裸 `(L^p)`）。
7. 已放行的成品哈希变了：先查 `annots()` 和 `modDate`——多半是用户自己的批注，不是被篡改。

## 4. 验收结论怎么写

日志里一条：日期 时间 · Claude 验收 <任务号> · 结论（通过/退回/修补后通过）· 阻塞项（逐条：位置 + 问题 + 修法）· 非阻塞项（记录）· 扫描结果 · 产物路径。退回时把阻塞项原样写成返工任务书的阻断项。

对用户只说人话：成品在哪、能不能读了、有什么需要他拍板。
