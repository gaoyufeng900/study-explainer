# 写法总纲

用户的写法偏好变过几次，**越新的越优先**。下面按「现在有效」的顺序写，旧规矩放在最后并注明被谁推翻。

## 1. 读者是谁

- 数学专业高年级，**数学推理不弱**，但前置课（数分、线代、实变）基础差，「回忆一下…」对他无效。
- **编程完全零基础**：`=` 是赋值不是等式、`print`、`import`、缩进、`#`、`**`、`1.0e16`、`assert` 通过时什么都不打印——每个符号第一次出现都要讲。Jupyter 的 cell、`Shift+Enter`、`[3]` 是执行序号不是行号、Restart Kernel 也要教。
- 老师口音重听不懂，**我们的 PDF 是课堂替代品，不是补充**：只读老师 PDF + 我们的 PDF，必须能学会。
- 在 iPad 上读，只读 PDF，会直接在 PDF 上批注。

## 2. 现行写法（2026-09-29 用户换打法后）

用户反馈旧卡「学起来费力」，四项全选：太长太密 / 表格和格式太多 / 英文 Proof 难读 / 缺直觉和图。于是：

1. **先直觉，再定义，配图**：每个核心概念先用一两句话说「它在干嘛」，能画就画（TikZ 或 matplotlib，图要简单），再给定义和证明。
2. **少表格、少格式**：正文用自然段。符号表只收新出现的符号、最多一张小表。不再逐条挂「八步/十步」小标题、不再每条挂原文锚点（每节开头写一次出处页码即可）、不写「原文条目对照表」「批注区」。
3. **证明用中文写**，关键术语首次出现括注英文。
4. 用户有视频、中文教材当主线时，我们只做它们做不到的事：老师编号↔视频↔教材对照、老师独有内容、老师讲义笔误、作业讲解、考前复习。

## 3. 复习类：「零基础也能看懂」（2026-10-09）

用户原话：「细致程度是即使我的基础特别差、甚至没有，也能看懂；需要补充的知识点可以先在前面补充。」

- **细 ≠ 密**：不再按「短」压篇幅，但仍是短句、多分段、一段只讲一件事、同一知识点只讲一次（别处指路）。灌水和重复才是退回理由，篇幅长不是。
- 前置知识**单独成册**放在前面，从最底层补起，按依赖顺序编号 K1、K2…；每条：**一句人话 → 带数字的小例子 → 一个「不是它」的反例 → 能画就配图**，结尾写「后面哪些题型会用到」。
- 解题每一步写「做什么 + 为什么这样做 + 靠哪条定理/定义」，**禁「显然」「易知」「不难看出」**。
- 定理写成「条件 ⇒ 结论」，补一句直观解释和「条件缺了会怎样」（指到反例），把**最容易漏的那个条件**单独点出来。
- 考试是英文卷时，给 1–2 句可直接写在卷子上的英文模板句，其余全中文。

## 4. 语言分科

| 科目 | 规则 |
|---|---|
| 数学类 | 中文讲解；术语首次出现写「中文（English）」；没有公认中译的**保留英文并解释，不硬造**（反例：native norms 被译成「母语范数」，应为「标准范数」）；原文定义/定理照抄英文后**紧跟逐句中译** |
| 编程部分 | 代码、环境、工程规范、逐行旁注全中文 |
| 大学物理 | **完完全全中文**，不做术语中英对照；只保留物理量符号、单位、人名 |

数学证明的语言：现行是中文（第 2 节第 3 条）。更早的「中文讲解 + 英文简洁 Proof」只对旧成品有效。

## 5. 用词禁令（去 AI 腔）

自造的术语读着别扭，一律不用：笺注、钩子、六件套、档位、★○△、诚实预计、预计用时、一句话带走、覆盖自查表。判断法：**人类老师会这么说话吗**。少用箭头链（只在依赖图里用）、少用「值得注意的是」「我们不难看出」这类填充语；emoji 不撒在正文里。

## 6. 讲解的硬功夫（任何格式都适用）

- **概念先于清单**：原文一上来抛一串例子时，先整节讲透「这个概念是什么、想解决什么、判定标准是哪几条」，再逐例回扣。（来历：读完 11 个函数空间例子仍不知道「函数空间」是什么，因为锚点把老师唯一正面回答的那页跳过了。）
- **符号必讲**：怎么读 / 什么意思 / 在这里具体指什么 / 代一个数进去算一次；复合记号拆开讲。
- **原文要你验证的**（`(check!)`、`(why?)`、Exercise）当场做完；**原文跳步**（obviously、was proved in analysis）当场补全，把前置课当没学过。
- **外部定理就地给完整陈述**并逐条核对前提在此处是否满足。
- **例子要真的算出来**：写清代进去的是哪个定义、每步在算什么、算完说明什么。
- 演示做法时，如果题目要学生自己产出某个数，**换一组数**演示（讲 √4.01−2 而不讲题里的 √9.01−3）。
